# NEXUS

NEXUS is a React, TypeScript and Vite super-app. Profile, progression, projects, games, creator drafts, communities, events, challenges and preferences are local to the browser. Creator League accounts provide server-backed rankings, friendships, online direct messages and creator uploads. Voice/video calls use the app's WebSocket signaling service.

## Run locally

Requires Node.js 20 or later.

```powershell
npm install
npm run dev
```

`npm run dev` starts Vite, the local WebSocket call-signaling server, and the Creator League API. The API listens on `127.0.0.1:8788` by default and is proxied by Vite under `/api/creator-league`. In Messages, start an audio or video call and share its invite code with the other person; they can join with that code. Calls use browser microphone/camera permissions and WebRTC, so camera and microphone access requires localhost or HTTPS. The signaling server relays connection setup only; media streams are peer-to-peer and are not recorded by NEXUS. Call history (contact name, call type, start time and connected duration) is saved locally in this browser.

Open **My Profile → Developer Console**. On first use from localhost during development, create a developer email and a password of at least 12 characters; the password is stored only as a scrypt hash in the private League data directory. You will be signed in after setup and can sign out or sign in again with those credentials. This one-time setup endpoint is disabled in production and is available only to loopback requests. For hosted environments, configure `NEXUS_DEVELOPER_EMAIL` and `NEXUS_DEVELOPER_PASSWORD` on the server instead.

Create and preview a production build locally:

```powershell
npm run build
npm run preview
```

## Deploy online

The production server serves the built app and routes Creator League API and WebSocket calls through the same origin. On a Node.js 20+ server, run:

```sh
npm ci
npm run build
npm start
```

Set the platform's start command to `npm start` and its build command to `npm ci && npm run build`. The server listens on `0.0.0.0` and uses the platform's `PORT` (default `3000`). Put it behind HTTPS using the platform's TLS or a TLS reverse proxy; the app, Creator League API, and calls should be reachable on the same HTTPS domain. Do not expose the internal `LEAGUE_PORT` (default `8788`) or `CALLS_PORT` (default `8787`) to the internet.

Set `LEAGUE_DATA_DIR` to persistent private storage. This directory contains accounts, friendships, messages and uploaded videos; back it up and do not place it inside the publicly served `dist` directory. The JSON-backed League service is intended to run as one application instance with a persistent disk; it is not a shared database for multiple replicas. Set `NEXUS_DEVELOPER_EMAIL` and `NEXUS_DEVELOPER_PASSWORD` as server-side environment variables to enable the Developer Console. Do not commit credentials or put them in `VITE_` variables. `.env.example` lists the available deployment settings. If a trusted TLS reverse proxy sits in front of this server and supplies the real client IP in `X-Forwarded-For`, set `TRUST_PROXY=true`; otherwise leave it false.

On the first visit, users must create an account with an email and a password of at least 12 characters; later visits require signing in. The application state is saved to that account on the server and restored after login on another device. Browser-only media (such as local stories and unpublished Creator Studio files) remains in that browser's storage; upload videos to Creator League if they need to be available online.

Online messaging requires a signed-in Creator League account; direct conversations are available with accepted Creator League friends. Messages sync while the Messages view is open. Existing local conversations and group chats are not uploaded or synchronized. Calls use a public STUN server for peer discovery; to support networks that block direct peer connections, configure a TURN REST service using `TURN_URL` (comma-separated `turn:`/`turns:` URLs) and its shared `TURN_SHARED_SECRET`. The app issues short-lived TURN credentials; set `TURN_TTL_SECONDS` to adjust their lifetime (60–3600 seconds). Keep the shared secret server-side. The League server and signaling server run as child processes of `npm start`; stopping or restarting the app also restarts them.

Creator League uses private server-side storage for account hashes, sessions, engagement records and uploaded videos. Seasons follow the UTC calendar in four-month blocks: January–April, May–August, and September–December. The seasonal score used for achievements and awards weights Content 40%, Creator 25%, and Quality 35%. Content combines unique views, unique watch minutes, likes, comments, saves and shares with logarithmic diminishing returns; Quality is qualified viewers' watched time divided by available video time. Watch time is capped at one video duration per viewer/video. Creator actions include recorded challenge, project, community, collaboration and battle-winner actions. Viewer actions are unique per account/video; self-engagement is excluded and a view requires up to three seconds of playback (the full duration for shorter clips). The League feed and its videos are visible to signed-in League users. The finalized top ten receive a place-specific badge, title and profile border, and the top three additionally receive a theme and trophy. Uploads are limited to two videos per day (100 MiB each); seasonal-score achievements unlock at 400/750/1100 Creator League points, while the Kauden tekijä achievement requires 15 published videos in the season.

Competitive Creator Score and Creator Rank are separate from seasonal score, Battle League CLP/Rank, and NEXUS/ONE AETHER's persistent Creator Level. Creator Score is recalculated from the last 30 days and capped at 10,000. Each video is scored separately using the Content/Creator/Quality formula above; videos scoring at least 20/100 are qualified. Score combines the qualified videos' mean (65%), consistency (25%, reaching its maximum at 10 qualified videos), and recent Creator action points (10%, logarithmically normalized at 100 action points). Thus one viral video cannot supply the consistency portion or dominate through unbounded raw views. Creator Rank is derived from that score across Rookie, Rising, Skilled, Elite, and Visionary, each with divisions III, II, I. Creator Level 0–160 remains lifetime XP progression and does not alter competitive score or rank.

The League also provides Global, Friends and Country season rankings (Country uses an optional two-letter country code on account registration), username-based friend requests, a seven-day Rising Creators list, a weekly themed Creator Battle capped at 100 unique participants, and rotating weekly video challenges. From the Battle's Submit Clip button, a signed-in creator selects a video (100 MiB upload limit), which is uploaded to the League feed and entered in the Battle; an existing League video can also be entered. A creator may enter once per week. Signed-in users rate creativity and editing from 1–5, while engagement and video Quality add system-scored components. The top submission with at least one community rating wins 25 League Rating and a Battle Winner badge. Weekly challenges validate that a selected own publication meets the configured duration and can be completed only once per challenge/week; completion adds 10 season Creator score and 25 local Creator XP, plus a challenge badge. Battle votes, actions and friend requests are stored in the League JSON data. Watch progress is paced against server elapsed time, but video duration is read by the browser and sent with the upload; a modified client can falsify duration or activity signals. Projects, communities, quests and group chats are local-only, so their authenticated events are client-reported rather than proof of real multi-user participation. Add server-side media metadata validation and moderation before high-stakes competition. This first account release also lacks email verification and password reset.

Each account has a persistent League Profile: current rank and division progress, current-season leaderboard position, Peak Rank and a Season History snapshot. Ranks progress through Bronze, Silver, Gold, Platinum, Diamond, Master, Grandmaster and Challenger, with four divisions (IV to I) per tier. Bronze IV requires 200 CLP; users below that are Unranked. Rank thresholds are rounded to 100-CLP increments from Bronze IV at 200 CLP through Challenger I at 10,000 CLP. CLP continues accumulating beyond that threshold and updates the all-time CLP leaderboard. Peak CLP is stored separately and never decreases; ended seasons retain their best rank, while newly finalized seasons add a history entry. Earlier finalized seasons that predate this profile history cannot be reconstructed reliably and are not fabricated. Battle wins award CLP; there is not yet a points-loss/decay mechanic.

On the production build, the app registers a service worker so the app shell and same-origin assets can be reused offline. Installability and service-worker behavior require serving over localhost or HTTPS.

## Local data and backup

The app uses a restrained forest-green visual theme, with Canopy and Pine variations in Appearance settings. Navigation stays visible on smaller screens as a labeled sidebar. The interface language (Finnish or English) is chosen in **Settings → Appearance**; English is applied by `src/i18n.ts`, which translates the Finnish UI text, so new Finnish strings need a matching entry there. Profile and app data are stored in browser `localStorage` under `nexus.local.v3`; XP totals, daily counters, event keys, and history use the same-origin ONE AETHER `one-xp-v1` record as their shared source of truth. Updates are shared across open tabs, and valid One Aether XP overrides any older copy in a NEXUS save. Image and video stories are stored separately in IndexedDB. Existing `nexus.local.v1` and `nexus.local.v2` state is migrated on first load. In **Settings → Backup & restore**, export a `nexus-backup.json` file or import a validated backup. Story media is not included in that JSON backup. Clearing this browser's site data removes the local copy, so keep an export if you want a separate backup.

## Prototype boundaries

Games, mini-games, projects/kanban, communities, local text conversations with emoji insertion, outgoing-message editing, local message deletion, per-message emoji reaction pickers, locally created group conversations with editable profiles and member roles, events, challenges, progression, profile settings, creator drafts and local video publishing, locally stored image/video stories, hash navigation, and appearance settings have local interactions. Group chats can be created from existing local conversations; their creator can change the group name and picture, appoint administrators, and remove members. Group creators and administrators can also remove other members' messages. Local conversations, groups, stories, drafts, locally published Creator Studio videos, projects and communities stay in this browser. Signed-in Creator League users can start server-stored direct messages with accepted friends; message content is not end-to-end encrypted. Creator League accounts, friendships, uploaded league videos, points, standings and season awards are server-backed. XP follows the ONE AETHER progression rules: 500 XP per level, total level 1–460, category levels 1–160, one Activity XP per five active minutes (250 daily maximum), 2 Social XP per message (20 daily maximum), 10 Social XP per story, 25 Creator XP per video story or Creator Studio video (two daily maximum combined), and 10 Social XP per community joined. Gaming awards 2 XP per 10 verified play minutes without a daily gaming cap. Category and total XP caps, daily counters, and event de-duplication are saved in `one-xp-v1`. Progression uses ONE AETHER's reward catalog of total-level titles, items and badges: rewards unlock every ten levels through level 150, then every 20 levels through level 450, with a final level-460 reward; NEXUS-specific rewards have been removed. Creator Studio videos are saved locally to IndexedDB; signing in and adding one to the League uploads its file to the server and does not move the local feed to the server. When NEXUS is hosted alongside the authenticated ONE AETHER service, Gaming XP syncs from `/api/activity` and Creator Battle wins sync at +500 Creator XP each; unavailable or unauthenticated endpoints are reported in the XP view. Voice/video calls use temporary invite-code rooms on the WebSocket signaling service and are not linked to authenticated identities or the locally stored message history.
